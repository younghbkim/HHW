# My MTS - 배포 및 사용 가이드

개인 자산 관리 PWA 대시보드. 4개 탭(종합 / 금융기관 / 종목 / 자동매수)으로 구성되며, 구글시트를 백엔드로 사용합니다.

본 가이드는 사용자의 실제 구글시트 구조에 맞춰 작성되어 있습니다.

---

## 사용 시트 (4개)

| 시트명 | 용도 |
|---|---|
| `01. 투자원금 및 수익 현황` | 평가금액·원금·수익률·투자기간 (히어로 + 차트) |
| `02. 종합자산(요약)` | 금융기관별·종류별·자산비중별 사전 집계 데이터 |
| `03. 종합자산(기초데이터)` | 종목 단위 raw 데이터 (금융기관·종목·종류 등) |
| `05. 자동적립설정현황` | 자동매수 설정 |

> 04번 시트(`종합자산(계좌&종목)`)는 종목 마스터(국내/미국, 종류, 위험/안전 분류) 데이터로 본 앱에서는 **사용하지 않습니다**. 03번에 같은 컬럼이 있어 03번만으로 충분합니다.

## 1. Apps Script 배포

### 1-1. Apps Script 설정

1. 구글시트를 열고 **확장 프로그램 → Apps Script** 클릭
2. 기존 코드 모두 삭제 후 `Code.gs` 파일 내용을 붙여넣기
3. **저장** (💾 또는 Ctrl+S)
4. 함수 드롭다운에서 `buildPayload` 선택 → ▶️ 실행 → 권한 검토/허용
5. 실행 결과가 정상이면(에러 없음) OK

### 1-2. 웹 앱 배포

1. Apps Script 우측 상단 **배포 → 새 배포**
2. 유형 선택(⚙️) → **웹 앱**
3. 설정:
   - 설명: `My MTS API v1`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자** (인증 없이 PWA가 호출하려면 필수)
4. **배포** → 권한 부여 → **웹 앱 URL** 복사
   - 형식: `https://script.google.com/macros/s/AKfyc.../exec`

### 1-3. 정상 작동 확인

웹앱 URL을 브라우저에 직접 입력해서 JSON이 반환되는지 확인:

```json
{
  "updatedAt": "2026.05.06 14:30",
  "summary": {
    "eval": 87316200,
    "cost": 60000000,
    "pnl": 27316200,
    "roi": 45.5,
    ...
  },
  ...
  "warnings": []
}
```

`warnings` 배열이 비어있어야 정상입니다. 비어있지 않으면 어느 시트의 파싱이 실패했는지 표시됩니다.

## 2. PWA 호스팅

### 2-1. URL 적용

`index.html`을 텍스트 에디터로 열어 상단 `<script>` 블록의 두 줄을 본인 값으로 교체:

```javascript
const API_URL   = 'https://script.google.com/macros/s/AKfyc.../exec';   // 1-2에서 복사한 URL
const SHEET_URL = 'https://docs.google.com/spreadsheets/d/1m1QyW.../edit';   // 본인 시트 URL
```

### 2-2. 파일 구성

다음 파일을 한 폴더에 두고 정적 호스팅하면 됩니다:

```
my-mts/
├── index.html
├── manifest.json
├── sw.js
└── icons/
    ├── icon-192.png
    └── icon-512.png
```

`icons/` 폴더에는 192×192, 512×512 PNG 아이콘을 직접 만들어 넣으세요. 임시로는 단색 사각형도 OK.

### 2-3. 추천: GitHub Pages

1. GitHub에 새 repo 생성 (예: `my-mts`)
2. 위 4개 파일 + 아이콘 업로드 (또는 git push)
3. Settings → Pages → Source: `main` branch / root → Save
4. 발급된 URL 접속 (예: `https://username.github.io/my-mts/`)
5. 모바일 사파리/크롬에서 접속 → "홈 화면에 추가" → 앱처럼 사용

### 2-4. 캐시 갱신

코드 수정 후 사용자가 캐시된 버전을 보는 문제를 막으려면 `sw.js` 상단의 버전을 올리세요:

```javascript
const CACHE_NAME = 'mymts-v2';   // v1 → v2
```

## 3. 시트 구조 참고 (이미 작성된 본인 시트 기준)

### 3-1. `01. 투자원금 및 수익 현황`

```
[행 31]  구분 | 2026.2.28 | 2026.3.31 | 2026.4.30 | 2026.5.31 | ...
[행 32]  투자원금  | 40,000,000 | 40,000,000 | 60,000,000 | 60,000,000
[행 34]  평가금액  | 50,000,000 | 60,000,000 | 75,000,000 | 87,316,200
[행 36]  (월간) 수익     | 0 | 10,000,000 | -5,000,000 | 12,316,200
[행 37]  (월간) 수익률   | 0.0% | 25.0% | -8.3% | 20.5%
[행 39]  (누적) 수익     | 10,000,000 | 20,000,000 | 15,000,000 | 27,316,200
[행 40]  (누적) 수익률   | 25.0% | 50.0% | 25.0% | 45.5%
[행 42]  투자기간(일)    | 89 | 120 | 150 | 181
[행 43]  연평균수익률(%) | 102.5% | 152.1% | 60.8% | 91.8%
```

파서는 B열(`구분`, `평가금액`, `투자원금` 등) 라벨을 자동 탐색하므로 행 번호가 바뀌어도 동작합니다.

### 3-2. `02. 종합자산(요약)`

4개 섹션이 있습니다. 헤더 행은 자동 탐색되어 행 번호가 달라져도 됩니다.

```
[금융기관별]
  금융기관 | 평가금액의 SUM | 평가금액의 SUM
  미래에셋증권 | 58,769,700 | 67.31%
  신한은행 (퇴직연금 DC) | 28,546,500 | 32.69%
  총계 | 87,316,200 | 100.00%

[종류별]
  종류 | 종목명 | 평가금액의 SUM | 평가금액의 SUM
  TDF | ACE TDF장기자산배분액티브 | 2,709,000 | 3.10%
       | ACE TDF2050액티브 적격     | 2,470,000 | 2.83%
  TDF 총계                        | 5,179,000 | 5.93%
  ...

[자산 비중별]
  위험/안전 | 평가금액의 SUM | 평가금액의 SUM
  위험      | 73,955,000     | 84.70%
  안전      | 13,361,200     | 15.30%

  국내/미국 | 평가금액의 SUM | 평가금액의 SUM
  국내      | 60,731,500     | 69.55%
  미국      | 26,584,700     | 30.45%
```

### 3-3. `03. 종합자산(기초데이터)`

| A | B | C | D | E | F | G | H | I | J | K | L | M |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| **금융기관** | 유형구분 | **종목번호** | **종목명** | (종목번호)종목명 | (빈) | 현재가 | 보유수량 | (빈) | **평가금액** | **국내/미국** | **종류** | **위험/안전** |
| 미래에셋증권 | ETF | 0021E0 | ACE TDF2050액티브 적격 | (0021E0) ACE TDF2050... |  | 12,350 | 100 |  | 1,235,000 | 미국 | TDF | 안전 |

- 헤더는 9행 부근. 1~8행은 ETF가격·총합계 등 보조 데이터로, 자동 무시됨
- 같은 금융기관에 같은 종목번호로 여러 행이 있으면 자동 합산
- `유형구분`, `(종목번호)종목명`, 빈 컬럼은 무시됨

### 3-4. `05. 자동적립설정현황`

```
[적립식 자동 매수 설정 현황]   ← 1행

금융기관 | 계좌명 | 종목명 | 금액 | 자동 매수 일자   ← 3행 헤더
미래에셋증권 | 연금저축 (0021) | KODEX 200타겟위클리커버드콜 | 150,000 | 매월 25일
미래에셋증권 | 연금저축 (0021) | ACE TDF2050액티브 적격     | 150,000 | 매월 25일
...
```

- 금융기관·계좌명이 비어있으면 위 행에서 자동 상속 (forward-fill)
- 종목명이 `없음`, `~`, `소계`, `합계`이면 스킵

## 4. 트러블슈팅

| 증상 | 원인 | 해결 |
|-----|-----|-----|
| 데이터 로드 실패: HTTP 401/403 | Apps Script 액세스 권한이 "모든 사용자"가 아님 | 1-2 단계 재확인 |
| 종합 탭 히어로가 0원 | 01번 시트의 B열 라벨 변경 (`평가금액` → 다른 이름) | 라벨을 `평가금액`, `투자원금` 등으로 복원 |
| 자산배분이 모두 0% | 02번 시트 `[자산 비중별]` 섹션의 `위험/안전`/`국내/미국` 헤더 미인식 | 헤더 셀 텍스트 확인 (앞뒤 공백 제거) |
| 종류별 자산이 안 보임 | 02번 `[종류별]` 섹션 헤더 미인식 | `종류`·`종목명`·`평가금액의 SUM` 셀 텍스트 확인 |
| 차트 데이터 1개만 표시 | 01번 시트 31행의 날짜 형식 인식 실패 | 날짜를 `Date` 셀 또는 `2026. 5. 31` 형태로 입력 |
| 자동매수 탭 빈 상태 | 05번 시트 헤더 미인식 | 3행에 `금융기관`, `종목명`, `금액` 헤더 정확히 입력 |
| 금융기관 탭에 신한은행이 안 보임 | 03번 raw 데이터에 신한은행 거래가 없으면 종목이 비어있음 | 02번 byInst만 사용해서 평가금액만 표시 (이미 자동) |

### Apps Script 디버깅

API 응답에 `warnings` 배열이 있으니, 브라우저 개발자도구 콘솔에서:

```
[My MTS warnings] ['parseInvest: ...', 'parseSummary: ...']
```

같은 메시지가 보이면 해당 파서가 실패한 것이니 그 시트를 점검하세요.

## 5. 디자인 변경

CSS 변수가 `:root` 에 정의되어 있으니 색상 톤만 바꾸려면 거기서 수정:

```css
:root {
  --blue:#185FA5;     /* 메인 컬러 */
  --green:#3B6D11;    /* 수익 */
  --red:#A32D2D;      /* 손실 */
  ...
}
```

자산 종류별 색상은 `index.html` 의 `KIND_COLORS` 객체에서 추가/변경 가능합니다.
시트 데이터에서 새 종류(예: `커버드콜`, `펀드`)를 추가하면 매칭 색상도 만들어주세요.
